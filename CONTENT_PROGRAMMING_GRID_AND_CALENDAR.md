# Content Programming Grid & 30-Day Launch Calendar

## 1. The 3-Tier Programming Grid

To maximize algorithmic distribution without overwhelming production, all content is bucketed into three complementary tiers:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ TIER 1: VIRAL SHORTS (Top of Funnel · 3x / week)                                       │
│ • Format: 15-second vertical (9:16) micro-sitcoms & retro tech disasters               │
│ • Role: Subscriber magnet, algorithm discovery, TikTok/Reels cross-syndication        │
│ • Conversion: Pinned "Related Video" link to that week's long-form VOD                 │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ TIER 2: LONG-FORM RETRO CHILL TAPES (Middle of Funnel · 1-2x / week)                   │
│ • Format: 2–3 hour landscape (16:9) 4K/1440p spatial sessions                         │
│ • Role: Search traffic, binge sessions, high-RPM AdSense ($4.20+), core audience trust  │
│ • Content: Classic Nintendo longplays (Mario, Zelda, Metroid) + original chiptune/lofi │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ TIER 3: 24/7 AUTONOMOUS LIVESTREAM (Bottom of Funnel · Always On)                      │
│ • Format: Continuous 4K30 RTMP stream with 4x circadian scene shifts                   │
│ • Role: 4,000 watch hours generator, live chat community, passive background revenue  │
│ • Interactivity: Live Concierge Bot, ephemeral unlock codes, Spotify links             │
└────────────────────────────────────────────────────────────────────────────────────────┘
```
